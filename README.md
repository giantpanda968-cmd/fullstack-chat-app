# 💬 Full Stack Chat App

A real-time full-stack chat application built with React, Node.js, Express, MongoDB and Socket.IO.

Users can create an account, login, update their profile, see online users and exchange messages in real time.

## 🚀 Features

- 🔐 User Signup & Login
- 🔒 Authentication with Cookies
- 💬 Real-time Messaging
- 🟢 Online / Offline User Status
- 👤 User Profile
- 📷 Profile Picture Upload
- 🎨 Multiple DaisyUI Themes
- 🌙 Dark / Light Theme
- ⚡ Real-time updates using Socket.IO
- 📱 Responsive UI
- 🔔 Toast Notifications
- 🔄 Persistent Authentication
- 🚪 Logout functionality

## 🛠️ Tech Stack

### Frontend

- React.js
- Vite
- Tailwind CSS
- DaisyUI
- Zustand
- React Router
- Axios
- Socket.IO Client
- Lucide React
- React Hot Toast

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- Socket.IO
- JWT Authentication
- Cookie Parser
- CORS
